# 📱 PocketApps

> A growing collection of useful mini web applications built with React.

PocketApps is an all-in-one collection of everyday tools and utilities, designed to be fast, responsive, and easy to use. Instead of managing multiple standalone projects, PocketApps brings them together in a single application with a clean and consistent user experience.

Whether you need to calculate something, manage tasks, test your typing speed, or use other handy utilities, PocketApps keeps everything in one place.

## 🛠️ Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/pocketapps.git
```

### Navigate into the project

```bash
cd pocketapps
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
